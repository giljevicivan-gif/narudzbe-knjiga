# Narudžbe knjiga

Program za narudžbe udžbenika (Knjižara PETICA). Ovdje je samo kod programa –
podaci (baza kupaca i narudžbi) su samo na računalu u knjižari.

**Nadogradnja:** program sam provjeri `verzija.txt` u ovom repozitoriju. Kad je ovdje
novija verzija, u programu se pojavi žuta traka "Nadogradi sad".
Za novu verziju: promijeni `VERZIJA` u `knjige.py` i isti broj upiši u `verzija.txt`.
